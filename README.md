# Halo-Mass-Relations

This repository contains the code and plots used in **Van Kempen et al. 2025** - [https://arxiv.org/abs/2508.12556](https://arxiv.org/abs/2508.12556)

## Overview

This work derives two complementary halo mass relations to improve observational estimates for galaxy group halo mass relations:

1. **Modified Virial Theorem (MVT)** - A physically-motivated approach that accounts for deviations from the standard virial theorem in galaxy groups
2. **Summed Stellar-Halo Mass Relation (sSHMR)** - A relation that connects the total stellar mass of group members to the halo mass

## Methodology

The analysis employs Markov Chain Monte Carlo (MCMC) techniques to derive these relations, providing robust statistical constraints on the relationship between observable galaxy properties and dark matter halo masses. By combining these two complementary approaches, this work enables more accurate estimates of halo masses for galaxy groups from observational data.
